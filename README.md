# Computational Physics Codes

This repository contains a collection of numerical and computational physics
programs developed during MSc Physics coursework and independent exploration.
Each script is self-contained and focuses on solving a standard physics problem
using established numerical methods.

The codes emphasize physical correctness, algorithmic implementation, and
clarity over optimization or packaging.

---

## Topics Covered

### Quantum Mechanics
- **1D Infinite Potential Well** – Shooting method for energy eigenvalues
- **Quantum Harmonic Oscillator** – Shooting method
- **Anharmonic Oscillator** – Variational method using Hamiltonian matrix diagonalisation

### Classical Mechanics & Nonlinear Dynamics
- **Coupled Pendulum System**
- **Forced and Damped Oscillator** (Runge–Kutta method)
- **Simple Harmonic Oscillator Phase Space** (RK4)
- **Transient Time vs Damping in Driven Oscillators**

### Statistical Mechanics
- **Metropolis Algorithm**
- **Creutz Demon Algorithm** (Microcanonical ensemble)
- **Entropy Estimation from Recurrence Statistics**

### Numerical Methods
- **Monte Carlo Integration**
- **Newton Interpolation (comparison-based implementation)**

### Electrodynamics
- **Electrostatic Lens Solver** using the Laplace equation

---

## Numerical Techniques Used
- Shooting methods for boundary-value problems
- Finite-difference approximations
- Runge–Kutta (RK4) time integration
- Variational principle and matrix diagonalisation
- Monte Carlo and Markov Chain Monte Carlo methods
- Iterative relaxation methods
